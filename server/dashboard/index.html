NODE VERWALTEN

Wartung

Vorübergehend herunterfahren

Für Updates oder einen Neustart. Persistente Daten bleiben auf dieser Node und werden nicht migriert. Lokale RAM-Inhalte gehen beim Beenden verloren. Zugriffe, die diese Node benötigen, warten auf ihre Rückkehr. Starte den Dienst anschließend wieder.

Geplant aus dem Cluster entfernen

Überträgt die Daten auf andere Nodes und fährt diese Node nach Abschluss herunter. Benötigt genügend freien Zielspeicher; bis dahin wartet die Migration.

Defekte Node mit Datenträgern ersetzen

Wenn die Node nicht zurückkommt, ihre Datenträger aber gerettet werden können. Die alte Node muss dauerhaft gestoppt oder vom Netz getrennt sein. Binde ihre Volumes anschließend auf einer anderen Node ein; betroffene Datenbereiche warten bis zur Übernahme.

Defekte Node ohne Datenträger entfernen

Wenn weder die Node noch ihre Daten wiederhergestellt werden können. Entfernt die Node dauerhaft aus dem Cluster. Ausschließlich dort vorhandene Daten gehen verloren. Die alte Node muss gestoppt oder vom Netz getrennt sein.

WIEDERHERSTELLUNG

Node ersetzen

Die Datenbereiche bleiben bis zur Übernahme der geretteten Volumes gesperrt. Binde die Datenträger anschließend auf einer verbleibenden oder neuen Node ein.
WIEDERHERSTELLUNG

Gerettete Volumes

Wähle die vorhandenen Datenträger der ersetzten Node aus. Zusammengehörige Volumes müssen gemeinsam übernommen werden.
CLUSTER RECOVERY

Node dauerhaft ausschließen

Ausschließlich auf dieser Node vorhandene Daten gehen verloren. Für einen vorübergehenden Neustart nutze stattdessen Wartung.
